# Unity 3D HW4 — Aircraft Obstacle Game

## 一、專案介紹

本專案製作 3D 飛行障礙遊戲。玩家可以透過滑鼠控制飛機的飛行軌跡，避開場景中的三棟建築物，完成飛行挑戰。

**開發環境**
- Unity：6000.6.2f1
- 程式語言：C#
- 開發平台：Windows

## 二、開發日誌（Development Log）

### 2026/10/22 — 專案建立與基本功能



**1. 匯入 3D 飛機模型**
- 匯入飛機與外觀。

**2. 建立遊戲場景**
- 建立飛行場景的地面。
- 配置三棟建築物(未導入模型)作為障礙物。
- 調整飛機起始位置及飛行高度。

**3. 飛行控制系統**
- 建立 `AircraftController.cs`。
- 使用 `Transform.Translate()` 實作飛機自動前進。
- 使用 `Input.GetMouseButton()` 偵測滑鼠拖曳。

**5. 攝影機系統**
- 建立 `CameraFollow.cs`。
- 使用 `LateUpdate()` 與 `Vector3.Lerp()` 設計攝影機跟隨功能。
